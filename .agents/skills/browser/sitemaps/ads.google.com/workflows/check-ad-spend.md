# Workflow: Check Campaign Performance & Spend (Google Ads)

## Goal
Check Campaign Performance & Spend on ads.google.com using Browser Use CLI 3.0.

## Verified Action Sequence
1. Attach to Google Ads profile 'adithya' on port 9307.
2. Navigate to https://ads.google.com/aw/campaigns.
3. Confirm active customer account ID.
4. Read campaign delivery status, daily spend, impressions, and conversions.
5. Stop before changing bids, budgets, or payment methods.
