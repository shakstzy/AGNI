# Page: App (gemini.google.com)

## Path
`/app`

## Purpose
Main Gemini interactive chat session with file upload, Deep Research, and voice controls.

## Semantic Anchors
  - **prompt_box**: `div.ql-editor`
  - **send_button**: `button[aria-label*='Send']`
  - **model_pill**: `button[data-test-id='model-picker-pill']`

## Key Elements
  - **chat_input**: Enter a prompt here (`textbox`)
  - **model_picker**: Model picker (`button`)
  - **file_upload**: Upload image or file (`button`)
  - **recent_chats**: Recent chats (`navigation`)
