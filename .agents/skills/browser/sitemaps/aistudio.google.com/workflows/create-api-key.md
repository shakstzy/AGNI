# Workflow: Create or Inspect Gemini API Key (aistudio.google.com)

## Goal
Create or Inspect Gemini API Key on aistudio.google.com using Browser Use CLI 3.0.

## Verified Action Sequence
1. Attach to Google AI Studio profile 'adithya' on port 9290.
2. Navigate to https://aistudio.google.com/apikey.
3. Confirm active Google Cloud project.
4. Inspect existing API keys or click 'Create API key'.
5. Copy created key into local environment or Bitwarden securely.
