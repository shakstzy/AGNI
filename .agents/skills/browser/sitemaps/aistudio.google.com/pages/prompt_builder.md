# Page: Prompt_builder (aistudio.google.com)

## Path
`/prompts/new_chat`

## Purpose
Gemini prompt design canvas with model parameter controls, token counts, and system instructions.

## Semantic Anchors
  - **prompt_input**: `textarea[aria-label*='prompt']`
  - **run_button**: `button:has-text('Run')`
  - **model_dropdown**: `mat-select[aria-label*='Model']`

## Key Elements
  - **prompt_box**: Prompt text area (`textbox`)
  - **model_selector**: Select model (`combobox`)
  - **system_instructions**: System instructions (`textbox`)
  - **temperature_slider**: Temperature (`slider`)
  - **run_btn**: Run prompt (`button`)
