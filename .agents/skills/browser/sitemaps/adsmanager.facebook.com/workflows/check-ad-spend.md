# Workflow: Check Campaign Performance & Spend (Meta Ads Manager)

## Goal
Check Campaign Performance & Spend on adsmanager.facebook.com using Browser Use CLI 3.0.

## Verified Action Sequence
1. Attach to Meta Ads profile 'adithya' on port 9255.
2. Navigate to Ads Manager campaigns dashboard.
3. Verify target Ad Account ID.
4. Read active campaigns, delivery status, spend today, and conversions.
5. Never edit budgets, publish new ads, or modify billing details.
