# Page: Profile (TikTok)

## Path
`/@<username>`

## Purpose
Public creator profile with bio, follower stats, and video grid.

## Semantic Anchors
  - **user_title**: `[data-e2e='user-title']`
  - **video_feed**: `[data-e2e='user-post-item-list']`

## Key Elements
  - **follower_count**: Follower Count (`[data-e2e='followers-count']`)
  - **video_cards**: Video Cards (`[data-e2e='user-post-item']`)
