# Page: Deposit (SMSPool)

## Path
`/deposit`

## Purpose
Manage account balance, view credit status, and review supported funding gateways (crypto, credit cards).

## Semantic Anchors
  - **balance_badge**: `.balance`
  - **payment_gateways**: `.payment-methods`

## Key Elements
  - **current_balance**: Account Balance Display (`.balance-amount`)
  - **deposit_methods**: Payment Method Options (`.payment-options`)
