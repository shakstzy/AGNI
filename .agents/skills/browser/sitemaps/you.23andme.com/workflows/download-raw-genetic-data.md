# Workflow: Download Raw Genetic Data

1. Navigate to `https://you.23andme.com/tools/data/download/`.
2. If redirected to login, authenticate using credentials from Bitwarden query `"23andMe"`.
3. Check for the download button:
   - If ready, click the download button to save the `.txt.zip` archive into `workspaces/health/state/raw/`.
   - If download requires request initiation, scroll down, tick confirmation checkbox, and click "Submit request".
   - Note that 23andMe sends an email notification when processing completes (usually 10-30 minutes).
