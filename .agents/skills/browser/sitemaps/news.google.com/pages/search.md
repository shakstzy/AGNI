# Page: Search (Google News)

## Path
`/search?q=<query>`

## Purpose
Filtered news article search results with chronological ordering.

## Semantic Anchors
  - **search_results**: `main article`
  - **time_stamp**: `time`

## Key Elements
  - **result_articles**: Search Result Articles (`article`)
  - **pub_time**: Publication Timestamp (`time`)
