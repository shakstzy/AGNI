# Workflow: Check App Release Status & Test Tracks (Google Play Console)

## Goal
Check App Release Status & Test Tracks on play.google.com using Browser Use CLI 3.0.

## Verified Action Sequence
1. Attach to Google Play Console profile 'adithya' on port 9304.
2. Navigate to https://play.google.com/console/developers.
3. Select target application package.
4. Read current production, open, closed, and internal testing track release statuses.
5. Stop before changing track rollout percentages or submitting for full review.
