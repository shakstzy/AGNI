# Workflow: Search Flights (American Airlines)

## Goal
Search Flights on aa.com using Browser Use CLI 3.0.

## Verified Action Sequence
1. Attach to American Airlines session on port 9234.
2. Navigate to https://www.aa.com.
3. Input origin, destination, and target travel dates.
4. Execute search and read flight options, fares, and cabin availability.
5. Stop before any booking confirmation or credit card entry.
