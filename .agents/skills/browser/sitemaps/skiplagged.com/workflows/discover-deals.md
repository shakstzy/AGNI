# Workflow: Discover Deals (Skiplagged)

## Goal
Scan featured low-fare glitch deals, price drops, and seasonal travel getaways on skiplagged.com.

## Verified Action Sequence
1. Navigate to `https://skiplagged.com/deals`.
2. Extract the deals grid items, filtering by departure region or origin code if specified.
3. Identify top percentage discounts (>30% off standard market price).
4. Extract travel dates and destination codes.
5. Surface candidates to the travel workspace for itinerary ranking.
