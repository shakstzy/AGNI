# Page: Deals (Skiplagged)

## Path
`/deals`

## Purpose
Real-time dashboard of featured low fares, error fares, price drops, and featured travel destinations.

## Semantic Anchors
- **deals_container**: `.deals-grid, #deals-container`
- **deal_card**: `.deal-card, .deal-item`

## Key Elements
- **deal_items**: Cards detailing origin, destination, discounted fare, original fare, and savings percentage.
- **discount_badge**: Percentage savings indicator.
- **book_deal_link**: Direct link into flight search itinerary for the deal dates.
