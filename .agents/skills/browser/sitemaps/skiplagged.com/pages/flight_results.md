# Page: Flight Results (Skiplagged)

## Path
`/flights/{from}/{to}/{depart}`

## Purpose
Displays interactive flight listings comparing standard non-stop and layover flights with Skiplagged hidden-city opportunities.

## Semantic Anchors
- **results_container**: `#results-container, .trips-container`
- **trip_card**: `.trip-item, .flight-card`
- **sort_filter**: `.sort-filter-bar, .filters`

## Key Elements
- **flight_cards**: Individual itinerary cards showing airline, departure time, arrival time, duration, and stops.
- **price_tag**: Fare displayed in USD.
- **hidden_city_tag**: Badge identifying hidden-city flights with layover warning.
- **select_btn**: Button opening detailed flight breakdown and booking handoff links.
