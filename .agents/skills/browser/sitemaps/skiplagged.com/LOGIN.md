# Skiplagged Login Reference

- **Profile**: Use `adithya` profile under `profiles/adithya/` (`profiles/adithya/metadata.json`).
- **Mode**: Guest searches and anonymous browsing are fully supported for search, comparison, and deals.
- **Vault Reference**: Query `Skiplagged` in Bitwarden folder `HADES` if linked account is configured.
- **Downstream Airline Portals**: For booking execution, route to native airline credentials stored in Bitwarden (`American Airlines`, `united.com`, `delta.com`, `southwest.com`).
- **Checkpoint Rule**: Stop on captcha, Cloudflare Turnstile, or human verification challenges.
