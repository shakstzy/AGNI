# Workflow: Check Developer Account Resources (Apple Developer)

## Goal
Check Developer Account Resources on developer.apple.com using Browser Use CLI 3.0.

## Verified Action Sequence
1. Attach to 'adithya' on port 9242.
2. Navigate to https://developer.apple.com/account/.
3. Confirm signed-in Apple ID and team selection.
4. Inspect certificate expiration dates and bundle identifier list.
5. Stop before revoking certificates or modifying team members.
