# cal.com

Scheduling infrastructure, booking pages, and calendar synchronization.

## Purpose
Automates Cal.com account creation, Google Calendar OAuth sync with `adithya@outerscope.xyz`, and booking link creation for Groundtruth outreach.

## Canonical URLs
- Home: `https://cal.com/`
- Signup: `https://cal.com/signup`
- Login: `https://cal.com/auth/login`
- Dashboard: `https://cal.com/event-types`

## Authentication
Google OAuth via `adithya@outerscope.xyz` with Bitwarden vault lookup and Android 2FA verification.
