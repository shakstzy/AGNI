# BusinessFinder Search Page

## Route
`/search`

## Purpose
Search and filter available business listings by keywords, NAICS / category, state / city, asking price, and reported cash flow (SDE).

## Elements & Interaction
- `search_input`: Keyword input (e.g., "laundromat", "auto repair")
- `location_input`: Metro or state filter (e.g., "Austin, TX")
- `listing_cards`: Card container list with brief financial stats, location badge, and direct URL to listing detail.
