# BusinessFinder Listing Detail Page

## Route
`/listing/:id`

## Purpose
Detailed dossier view of an acquisition candidate: asking price, reported gross revenue, reported cash flow / SDE, inventory / FF&E value, lease term, owner hours/involvement, and broker or seller representation.

## Key Fields
- `title`: Primary headline
- `asking_price`: Currency string
- `cash_flow`: SDE / EBITDA reported
- `revenue`: Annual gross sales
- `broker_name`: Listing agent name
- `broker_email`: Agent direct email or inquiry form hook
