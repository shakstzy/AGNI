# Workflow: Search SMB Listings

1. Navigate to `https://www.businessfinder.com/search`.
2. Enter target sector keyword in the search query field (e.g. `laundromat`, `hvac`, `car wash`).
3. Set location filter to target geography (e.g. `Texas` or `Austin, TX`).
4. Execute search and wait for `.listing-card` elements to render.
5. Capture listing IDs and URLs for detail extraction.
