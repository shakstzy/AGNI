# Workflow: Submit Acquisition Inquiry

1. On listing page, locate contact broker / seller form.
2. Fill buyer name: `Adithya Kumar` (or configured `BA_CONTACT_NAME`).
3. Fill buyer email: `adithya@outerscope.xyz` (or configured `BA_FORM_EMAIL`).
4. Fill inquiry message using non-binding acquisition conversation template.
5. Verify no binding LOI terms are submitted before operator review.
6. Submit form and record transaction key into contacted ledger.
