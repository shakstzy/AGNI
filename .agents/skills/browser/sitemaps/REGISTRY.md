## Standard Sitemap Directory Layout

Each sitemap directory under `sitemaps/<host>/` contains:
1. `ADAPTER.md`: Browser adapter documentation covering service ownership, Browser Use CLI 3.0 execution commands, human boundaries, and navigation.
2. `SITE.md`: High-level service overview, driver instructions (Browser Use CLI 3.0), and common goals.
3. `LOGIN.md`: Specific authentication procedures, credentials lookup pointer, and session guidelines.
4. `sitemap.json`: Canonical semantic selectors, anchors, element definitions, and postconditions.
5. `pages/`: Detailed descriptions and accessibility identifiers for individual routes.
6. `workflows/`: Step-by-step verified action sequences.
7. `profiles/<username>/`: Username-indexed Chrome browser profiles (`metadata.json` and `login.md`).
