# DistroKid Upload Page

- **URL**: `https://distrokid.com/new/`
- **Key Inputs**:
  - `input#file_art`: Cover art JPEG file (3000x3000px).
  - `input[name="file_track1"]`: Audio file WAV.
  - `input[name="trackTitle1"]`: Track title.
  - `input[name="artistName"]`: Artist name (`Shak STZY`).
  - `input[name="recordLabel"]`: Label (`Outerscope Records`).
  - `input.areyousure[type="checkbox"]`: Mandatory certification checkboxes.
  - `#saveAndContinue`: Submit button (appears after audio uploads to S3).
